# S3

Filesystem-backed S3 emulator. Objects are stored under `NIMBUS_DATA_DIR` (default `/var/lib/nimbus`).

## Supported operations

| Method | Operation |
|--------|-----------|
| PUT bucket | CreateBucket |
| DELETE bucket | DeleteBucket |
| PUT object | PutObject |
| GET object | GetObject |
| HEAD object | HeadObject |
| DELETE object | DeleteObject |
| GET bucket?list-type=2 | ListObjectsV2 |
| POST object?uploads | CreateMultipartUpload |
| PUT object?uploadId= | UploadPart |
| POST object?uploadId= | CompleteMultipartUpload |
| DELETE object?uploadId= | AbortMultipartUpload |
| GET presigned URL | Pre-signed GET/PUT |
| GET bucket?lifecycle | GetBucketLifecycleConfiguration — returns stored config or 404 NoSuchLifecycleConfiguration |
| PUT bucket?lifecycle | PutBucketLifecycleConfiguration — persists lifecycle XML to disk |
| DELETE bucket?lifecycle | DeleteBucketLifecycleConfiguration — removes stored config |

Detection: catch-all (path-style and virtual-hosted).

## Example

```bash
nimbuslocal s3 mb s3://my-bucket
nimbuslocal s3 cp ./file.txt s3://my-bucket/file.txt
nimbuslocal s3 ls s3://my-bucket
nimbuslocal s3 rm s3://my-bucket/file.txt
```
